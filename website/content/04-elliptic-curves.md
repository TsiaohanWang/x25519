## 4.2 曲线方程与对称性

Curve25519 使用的曲线是 **Montgomery 曲线**：

$$y^2 = x^3 + Ax^2 + x \tag{6}$$

其中 $A = 486662$。$x, y$ 是域元素——论文先用实数推导（方便画图和微积分），结论对任何域都成立；在 Curve25519 中它们是模 $p = 2^{255} - 19$ 的整数。

注意方程只含 $y^2$，所以曲线关于 $x$ 轴**反射对称**：$(x, y)$ 在曲线上当且仅当
$(x, -y)$ 也在曲线上。这个对称性是后面"逆元"定义的基础。

## 4.3 直线与曲线的第三个交点

设 $P = (x_P, y_P)$、$Q = (x_Q, y_Q)$ 是曲线上的两个点，$x_P \ne x_Q$。过 $P, Q$
画一条直线，斜率为

$$\lambda = \frac{y_Q - y_P}{x_Q - x_P}, \qquad \text{直线方程 } y = \lambda x + c,
\quad c = y_P - \lambda x_P \tag{8}$$

这条直线与曲线有几个交点？把直线代入曲线方程：

$$(\lambda x + c)^2 = x^3 + Ax^2 + x
\iff x^3 + (A - \lambda^2)x^2 + (1 - 2\lambda c)x - c^2 = 0 \tag{11}$$

这是一个三次多项式，最多有 3 个实根，即直线最多与曲线相交 3 次。我们知道 $x_P$
和 $x_Q$ 是其中两个根（因为 $P, Q$ 同时在直线和曲线上）。设第三个根为 $x_R$，把 (11) 除以已知因子 $(x - x_P)(x - x_Q) = x^2 - (x_P + x_Q)x + x_P x_Q$，做多项式除法：

$$
\begin{array}{l}
x + A - \lambda^2 + x_P + x_Q \\
x^2 - (x_P + x_Q)x + x_P x_Q \ \overline{) \ x^3 + (A - \lambda^2)x^2 + (1 - 2\lambda c)x - c^2}
\end{array}
$$

除法得到的商是 $x + A - \lambda^2 + x_P + x_Q$。商的**根**就是第三个交点的 $x$
坐标（其余项是余数，必然为零，因为 $x_P, x_Q$ 确实是根），所以

$$x_R = \lambda^2 - A - x_P - x_Q \tag{12}$$

把 $x_R$ 代回直线方程 (8) 得到第三个交点的 $y$ 坐标：

$$y_R = \lambda x_R + c = y_P + \lambda(x_R - x_P) \tag{13}$$

**$P = Q$ 的情况**：当 $P = Q$ 时，过两点的直线退化为**切线**。切线斜率由导数给出：

$$\lambda = \frac{\mathrm{d}y}{\mathrm{d}x} = \frac{3x^2 + 2Ax + 1}{2y} \tag{10}$$

（对 (6) 两边求导：$2y \,\mathrm{d}y = (3x^2 + 2Ax + 1)\,\mathrm{d}x$。）此时 (12)(13) 仍然成立，$x_R = \lambda^2 - A - 2x_P$。这称为**点倍增**。

## 4.4 用曲线点构造群

现在定义群。集合是曲线上所有点加上一个特殊的**无穷远点** $\infty$：

$$E = \{(x, y) \mid y^2 = x^3 + Ax^2 + x\} \cup \{\infty\} \tag{14}$$

$\infty$ 的用途是处理垂直线：当 $P = (x, y)$ 与 $Q = (x, -y)$（$x$ 相同、$y$ 相反）时，过两点的直线是垂直的，没有第三个有限交点。我们约定这条垂直线"与曲线相交于无穷远点"。可以想象 $\infty$ 位于 $y$ 轴方向无穷远处，所有垂直线都经过它。

**群运算的定义**：

- $\infty$ 是单位元：$P \bullet \infty = \infty \bullet P = P$；
- $P = (x, y)$ 的逆元是 $P^{-1} = (x, -y)$（关于 $x$ 轴的反射），因此$P \bullet P^{-1} = \infty$；
- 对一般的 $P, Q$：画过 $P, Q$ 的直线，取第三个交点 $R$（§4.3），然后定义
  $$P \bullet Q = R^{-1} = (x_R, -y_R)$$

为什么要"取反"而不是直接用 $R$？看三个共线点 $P, Q, R$：如果直接定义 $P \bullet Q = R$，那么 $(P \bullet Q) \bullet R$ 会绕回去而无法得到单位元，运算不成群。取反之后，$P \bullet Q = R^{-1}$，于是 $(P \bullet Q) \bullet R = R^{-1} \bullet R = \infty$，完美对应"共线三点之和为 $\infty$"。

**群律的显式公式**（来自 §4.3）：

$$x_3 = \lambda^2 - A - x_1 - x_2, \qquad
y_3 = \lambda(x_1 - x_3) - y_1 \tag{18,19}$$

其中 $\lambda = \frac{y_2 - y_1}{x_2 - x_1}$（$x_1 \ne x_2$）或$\lambda = \frac{3x_1^2 + 2Ax_1 + 1}{2y_1}$（$x_1 = x_2$，点倍增）。

**这个运算真的构成阿贝尔群吗？**检查公理：

- **封闭性**：由 (12)(13) 算出的点在曲线上；$\infty$ 参与的结果也是群元素。✓
- **单位元**：$\infty$，由定义。✓
- **逆元**：$(x, -y)$，由定义。✓
- **交换律**：过 $P, Q$ 的直线与过 $Q, P$ 的直线是同一条（可代入 (8) 验证），第三交点相同，所以 $P \bullet Q = Q \bullet P$。✓
- **结合律**：$(a \bullet b) \bullet c = a \bullet (b \bullet c)$——这是唯一需要高等数学或计算机代数才能证明的性质（参见论文引用的 [17][18]）。论文选择跳过证明，转而引用显式公式数据库 EFD 的独立验证。本教程同样承认结合律成立。

> **记号的提醒**：椭圆曲线文献通常把这里的 $\bullet$ 写作 $+$（"点加法"），把
> $P \bullet P$ 写作 $2P$。我们沿用论文的 $\bullet$ 记号以避免与域元素算术混淆，但心里要知道：$P^k$ 就是"把 $P$ 与自身运算 $k$ 次"，即协议文献中的标量乘法 $kP$。

## 4.5 Curve25519 的参数

- **域**：$\mathbb{Z}_p$，$p = 2^{255} - 19$。
- **曲线**：$y^2 = x^3 + 486662\,x^2 + x$。
- **群阶**：$|E| = 8q$，其中
  $$q = 2^{252} + 27742317777372353535851937790883648493$$
  是素数（$q = 0x1000000000000000000000000000000014def9dea2f79cd65812631a5cf5d3ed$，略大于 $2^{252}$）。
- **余因子**：$h = 8$。
- **基点**：$x$ 坐标为 9 的点 $g$（$g$ 的阶为 $q$，即它生成阶为 $q$ 的素数阶子群）。

可以用 SageMath 验证全部参数（论文代码清单 3）：

```python
field = GF(2^255 - 19)
# 方程 y^2 + a1*x*y + a3*y = x^3 + a2*x^2 + a4*x + a5，
# 取 a1=a3=a5=0, a2=486662, a4=1 得到 y^2 = x^3 + 486662*x^2 + x
E = EllipticCurve(field, [0, 486662, 0, 1, 0])

q = 2^252 + 27742317777372353535851937790883648493
q.is_prime()              # True
E.cardinality() == 8 * q  # True

# 基点：x 坐标 = 9 的点；q * g 是无穷远点 (0 : 1 : 0)，说明 g 的阶是 q
base = 9
g = [field(base), sqrt(field(base^3 + 486662 * base^2 + base))]
q * E(g)                  # (0 : 1 : 0)
```

## 4.6 余因子与小子群攻击

因为群阶 $8q$ 不是素数，拉格朗日定理告诉我们：任何群元素的阶必须是 $8q$ 的因子，即只能是 $1, 2, 4, 8, q, 2q, 4q, 8q$ 之一。如果攻击者 Alice 不发送阶为 $q$ 的合法点，而是发送一个**阶为 8 的点** $s$，那么 Bob 计算 $s^b$（$b$ 是 Bob 的私钥）时，结果只有 8 种可能（因为 $s$ 生成 8 元子群，$s^b = s^{b \bmod 8}$）。通过观察 Bob 的后续行为，Alice 可以暴力确定 $b \bmod 8$——私钥的最低 3 个比特泄露了。这就是**小子群限制攻击**（small-subgroup confinement attack）。

防御办法有几种：

1. **公钥验证**：收到点 $s$ 后检查 $s^q = e$（从而 $s$ 的阶整除 $q$）。
2. **乘以余因子**：X25519 采用的办法——确保标量是 8 的倍数。如果 $s$ 的阶整除 8，那么 $s^{8b} = (s^8)^b = e$ 恒为单位元，攻击者得不到任何信息；而对合法的阶 $q$
   的基点 $g$，$g^{8b}$ 的分布与 $g^b$ 相同（因为 $8$ 与 $q$ 互素，映射
   $b \mapsto 8b \bmod q$ 是双射）。这解释了第 13 章**钳位处理**中"把私钥最低 3 位清零"这一操作的来历。

## 4.8 小结

- 直线与椭圆曲线最多交 3 点；$x_R = \lambda^2 - A - x_P - x_Q$ 由多项式除法得到。
- 曲线点加 $\infty$ 构成阿贝尔群：逆元是 $x$ 轴反射，群律是"第三交点取反"。
- Curve25519：$y^2 = x^3 + 486662x^2 + x$ 在 $\mathbb{Z}_{2^{255}-19}$ 上，群阶$8q$，基点 $x = 9$。
- 余因子 8 带来小子群攻击风险，X25519 用"标量取 8 的倍数"（钳位）防御。
