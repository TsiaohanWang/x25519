# 第 2 章：群与 Diffie-Hellman 密钥交换

> 对应论文：§2.2 群、§2.3 Diffie-Hellman 密钥交换、§2.4 群的安全性质

## 2.1 本章要回答的问题

第 4 章我们会发现，椭圆曲线上的点可以定义一种"加法"，并且这些点构成一个**群**。
在走到那一步之前，本章先把"群"这个抽象概念讲清楚，并回答三个问题：

1. 群到底是什么？为什么密码学那么依赖它？
2. Diffie-Hellman 密钥交换协议是怎样工作的？它依赖群的什么性质？
3. 什么样的群才安全？为什么椭圆曲线群比"模 $p$ 整数乘法群"更好？

## 2.2 群公理

一个**阿贝尔群**是一个集合 $G$ 配上一个二元运算 $\bullet$（读作"群运算"），
对 $G$ 中任意两个元素 $a, b$，$a \bullet b$ 仍是 $G$ 的元素，并且满足：

1. **封闭性**：对所有 $a, b \in G$，$a \bullet b \in G$。
2. **结合律**：对所有 $a, b, c \in G$，$(a \bullet b) \bullet c = a \bullet (b \bullet c)$。
3. **单位元**：存在 $e \in G$，使对所有 $a \in G$ 有 $e \bullet a = a \bullet e = a$。
4. **逆元**：对每个 $a \in G$，存在 $b \in G$ 使 $a \bullet b = b \bullet a = e$，
   记 $b = a^{-1}$。
5. **交换律**（阿贝尔群特有）：对所有 $a, b \in G$，$a \bullet b = b \bullet a$。

$G$ 中元素的个数叫**群的阶**，记作 $|G|$。如果 $|G|$ 是素数，称为**素数阶群**，
它有特别好的性质（2.5 节）。

**例子 1：整数加法群 $(\mathbb{Z}, +)$。** 集合是所有整数，运算是加法，单位元 0，
$a$ 的逆元是 $-a$。这是一个无限群。

**例子 2：模 $n$ 整数加法群 $(\mathbb{Z}_n, +)$。** 集合 $\{0, 1, \ldots, n-1\}$，
运算是"加法后模 $n$ 归约"，单位元 0，$a$ 的逆元是 $n - a$。阶为 $n$。这是有限群。

**例子 3：模 $p$ 整数乘法群 $(\mathbb{Z}_p^*, \cdot)$。** $p$ 是素数，集合
$\{1, 2, \ldots, p-1\}$，运算是"乘法后模 $p$ 归约"，单位元 1。**并非显然**每个元素
都有乘法逆元，但 $p$ 为素数时这是对的（可由 Bézout 恒等式证明，也可由费马小定理
得出，见第 3 章）。群的阶为 $p - 1$。

这三个例子看似不同，但**数学结构相同**——它们都是群。抽象的力量在于：任何关于群的
定理，对三者都成立；任何在群上工作的协议（如 Diffie-Hellman），都**不关心群具体是
怎么实现的**。这一点在密码学中至关重要：协议设计者说"取一个素数阶群"，实现者可以
用整数、椭圆曲线或任何其他方式去实现它，只要满足公理。

## 2.3 群元素的幂与循环群

对群元素 $g$ 和非负整数 $k$，定义 $g$ 的 $k$ 次幂为把 $g$ 与自身运算 $k$ 次：

$$g^k = \underbrace{g \bullet g \bullet \cdots \bullet g}_{k \text{ 次}}, \qquad
g^0 = e, \qquad g^k = g \bullet g^{k-1} \ (k > 0)$$

注意这里 $g^k$ 只是"群运算的重复"的记号——在加法群 $(\mathbb{Z}_n, +)$ 中它就是
$k \cdot g$（$g$ 加 $k$ 次）。

**元素的阶**：使 $g^k = e$ 的最小正整数 $k$ 称为元素 $g$ 的阶。由封闭性，幂序列
$\{g^0, g^1, g^2, \ldots\}$ 是 $G$ 的子集；群有限时这个序列必然重复，且
$g^{\text{ord}(g)} = e$（**拉格朗日定理**：任何元素的阶整除群的阶 $|G|$）。

**循环群**：如果存在 $g \in G$ 使 $\{g^0, g^1, \ldots, g^{|G|-1}\} = G$，则 $G$ 是
循环群，$g$ 是**生成元**。循环群最重要的性质是：

> 如果 $G$ 是阶为 $q$ 的循环群，生成元为 $g$，那么从 $[0, q-1]$ 均匀随机选取 $k$
> 并计算 $g^k$，得到的群元素在 $G$ 中**均匀分布**。

这给了密码学一个"均匀采样群元素"的机制，后面 Diffie-Hellman 会反复用到。

**为什么素数阶群好**：可以证明素数阶群必为循环群，且除单位元外每个元素的阶都等于
$|G|$。也就是说，素数阶群里没有"小圈子"——这直接关系到第 4 章要讲的**小子群攻击**。

## 2.4 Diffie-Hellman 密钥交换

假设 Alice 和 Bob 要通过不安全的信道（攻击者只能窃听、不能篡改）协商一个共享秘密，
用来加密之后的通信。Diffie-Hellman（DH）协议如下：

1. 公开参数：一个素数阶群 $G$ 及其生成元 $g$（公开，谁都知道）。
2. Alice 选随机整数 $a$ 作私钥，计算 $A = g^a$ 作公钥并公开。
3. Bob 选随机整数 $b$ 作私钥，计算 $B = g^b$ 作公钥并公开。
4. Alice 用 Bob 的公钥计算 $(g^b)^a$；Bob 用 Alice 的公钥计算 $(g^a)^b$。

由结合律，$(g^b)^a = g^{ba} = g^{ab} = (g^a)^b$，两人得到**同一个**群元素
$g^{ab}$——这就是共享秘密。而窃听者只知道 $g$、$g^a$、$g^b$（全是公开的）。

**安全性的关键问题**：窃听者能否从 $g, g^a, g^b$ 算出 $g^{ab}$？如果群选得不好，
可以；如果选得好，这被认为是计算上不可行的。这就是下一节的内容。

## 2.5 群的安全性质：DLP、CDH、DDH

设 $g$ 是素数阶 $q$ 的群的生成元，$a, b, k$ 从 $[0, q-1]$ 均匀随机选取。三个层层递进
的假设：

- **离散对数问题（DLP）**：给定 $g$ 和 $g^k$，求 $k$ 是困难的。
- **计算性 Diffie-Hellman（CDH）**：给定 $g, g^a, g^b$，求 $g^{ab}$ 是困难的。
- **判定性 Diffie-Hellman（DDH）**：给定 $g, g^a, g^b$ 以及一个元素 $h$，判断
  $h$ 是 $g^{ab}$ 还是一个随机群元素，是困难的（即攻击者无法显著优于随机猜测）。

容易看出 DLP 困难 ⇒ CDH 困难 ⇒ DDH 困难（反过来不一定）。

**不同群的安全性质天差地别**：

- $(\mathbb{Z}_n, +)$：DLP 极易——解 $g \cdot k = x$ 就是普通除法，不安全。
- $(\mathbb{Z}_p^*, \cdot)$：DLP 被认为困难，但 **DDH 不成立**。原因：可以用
  Euler 判别准则判断 $g^k$ 是否为二次剩余，从而泄露 $k$ 的奇偶性。补救办法是取
  $\mathbb{Z}_p^*$ 的素数阶子群（DSA 就是这么做），但为了达到 128 位安全级别，
  $p$ 需要 3000 多比特长，密钥和消息都很大。
- **椭圆曲线群**（第 4 章构造）：DDH 被广泛认为成立，且相同安全级别下只需 256 位。

> **这就是椭圆曲线密码学的根本动机**：在同样的 128 位安全级别下，椭圆曲线群的
> 元素只需 32 字节，而 $\mathbb{Z}_p^*$ 需要几百字节；网络传输更省、计算更快。

## 2.6 记号约定（重要）

群运算的记号在不同文献中不同，本教程必须统一，否则容易混淆：

- 椭圆曲线文献传统上把群运算写作 **加法** `+`，$P$ 的逆元写作 $-P$，$P$ 与自身
  相加写作 $2P$（点倍增）。
- 密码学协议文献传统上写作**乘法** `·`，逆元写作 $P^{-1}$，$P$ 与自身相乘写作 $P^2$。

本教程沿用论文的约定：椭圆曲线群元素之间的运算用 **$\bullet$**，以区别于单个域元素
（模 $p$ 的整数）之间的 $+$、$\cdot$。这样"点加法 $P \bullet Q$"和"域元素加法
$a + b$"不会混淆。不过，说到 X25519 协议本身时（第 13、14 章），我们仍会说"私钥
$a$ 乘基点得到公钥 $aP$"这类惯用语，请留意上下文。

## 2.7 C 代码：验证 $\mathbb{Z}_7^*$ 是循环群

```c
#include <stdio.h>

/* 计算 a 在模 n 乘法群中的阶：最小的 k>0 使 a^k ≡ 1 (mod n) */
int element_order(int a, int n) {
    int power = 1, order = 0;
    do {
        power = (power * a) % n;   /* 依次计算 a, a^2, a^3, ... */
        order++;
    } while (power != 1);
    return order;
}

int main(void) {
    int n = 7;
    printf("Z_%d* 中各元素的阶（群的阶为 6）：\n", n);
    for (int a = 1; a < n; a++)
        printf("  元素 %d 的阶：%d\n", a, element_order(a, n));
    /* 输出：1 的阶 1；2、4 的阶 3；3、5 的阶 6；6 的阶 2。
       阶为 6（等于群阶）的元素 3 和 5 就是生成元。 */
    return 0;
}
```

## 2.9 小结

- 群是一个抽象的代数结构；素数阶群必为循环群，元素在群中均匀分布。
- DH 协议依赖"从 $g^a, g^b$ 无法算出 $g^{ab}$"。
- DLP/CDH/DDH 三个假设刻画了群的安全性；椭圆曲线群用 256 位达到 $\mathbb{Z}_p^*$
  用 3000 多位才达到的安全级别。

下一章我们把"模 $p$ 的整数"升级成**有限域**——一个同时有加法、减法、乘法和除法的
结构，这是椭圆曲线方程里所有坐标运算的舞台。
