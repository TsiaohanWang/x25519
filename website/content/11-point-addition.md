# 第 11 章：点加法与射影坐标

> 对应论文：§4.4 Montgomery 阶梯（射影坐标与公式推导部分）

## 11.1 本章要回答的问题

第 4 章给出了群律的仿射公式，但它含有**除法**（除以 $x_2 - x_1$ 或 $2y_1$）。在 $\mathbb{Z}_p$ 中除法 = 乘以逆元 = 一次 `finverse`（约 500 次 `fmul`），如果标量乘法每步都做除法，代价不可接受。本章回答：

1. 怎样把坐标改成"分数"形式，从而把除法推迟到最后一步？
2. 点倍增公式怎么推导？（它完全不使用 $y$ 坐标！）
3. 点加法公式怎么推导？（它需要知道 $P - Q$，这正是 Montgomery 阶梯提供的！）

## 11.2 仿射公式回顾

第 4 章推导的群律：对 $P_1 = (x_1, y_1)$、$P_2 = (x_2, y_2)$，$P_1 \bullet P_2 = (x_3, y_3)$，其中

$$x_3 = \lambda^2 - A - x_1 - x_2, \qquad y_3 = \lambda(x_1 - x_3) - y_1$$

$$\lambda = \begin{cases} \frac{y_2 - y_1}{x_2 - x_1} & x_1 \ne x_2 \\[2mm]
\frac{3x_1^2 + 2Ax_1 + 1}{2y_1} & x_1 = x_2 \end{cases} \tag{18,19}$$

这些公式在域 $\mathbb{Z}_p$ 中直接可用，但两个分母都需要求逆元。

## 11.3 射影坐标：把除法推迟到最后

引入**射影坐标**：把点写成分数 $x = X/Z$、$y = Y/Z$（$X, Y, Z$ 是域元素，$Z \ne 0$；$(X:Z)$ 与 $(\lambda X : \lambda Z)$ 表示同一个 $x$）。之前的 $(x, y)$
叫**仿射坐标**。

策略：在 Montgomery 阶梯的每一轮迭代中，只更新分子和分母（$X$ 和 $Z$），**不做任何除法**；等整个标量乘法结束后，才做一次除法 $x = X/Z$（一次 `finverse`
+ 一次 `fmul`）。于是 255 轮迭代中的除法从 255 次降到 1 次。

无穷远点 $\infty$ 在射影坐标下表示为 $Z = 0$（分母为零的分数），只要 $X \ne 0$。
$X = Z = 0$ 是非法的。第 12 章会证明公式自动正确处理 $\infty$，无需特殊分支。

## 11.4 点倍增公式的推导

设 $P = (x, y)$，$2P = (x_{2i}, y_{2i})$。由 (18) 中 $x_1 = x_2$ 的情形：

$$x_{2i} = \left(\frac{3x^2 + 2Ax + 1}{2y}\right)^2 - A - 2x$$

关键一步：**用曲线方程 $y^2 = x^3 + Ax^2 + x$ 消去 $y$**：

$$x_{2i} = \frac{(3x^2 + 2Ax + 1)^2}{4y^2} - A - 2x
= \frac{(3x^2 + 2Ax + 1)^2 - 4(x^3 + Ax^2 + x)(2x + A)}{4(x^3 + Ax^2 + x)}$$

展开分子（这是纯粹的代数化简，可以手工验证）：

$$(3x^2 + 2Ax + 1)^2 - 4(x^3 + Ax^2 + x)(2x + A) = x^4 - 2x^2 + 1 = (x^2 - 1)^2$$

代入 $x = X/Z$：

$$x_{2i} = \frac{(X^2/Z^2 - 1)^2}{4(X^3/Z^3 + AX^2/Z^2 + X/Z)}
= \frac{X^4 - 2X^2Z^2 + Z^4}{4XZ(X^2 + AXZ + Z^2)}
= \frac{(X^2 - Z^2)^2}{4XZ(X^2 + AXZ + Z^2)}$$

于是得到**点倍增的射影公式**：

$$\boxed{\,X_{2i} = (X_i^2 - Z_i^2)^2, \qquad Z_{2i} = 4X_iZ_i\,(X_i^2 + AX_iZ_i + Z_i^2)\;} \tag{25}$$

**注意 $X_{2i}$ 和 $Z_{2i}$ 的公式完全没有用到 $y$ 坐标！**这意味着我们可以从头到尾不算 $y$，连 $Y_{2i}$ 的表达式都不需要推导。

## 11.5 点加法（差分加法）公式的推导

现在推导 $P_{2i+1} = P_i \bullet P_{i+1} = (x_1, y_1) \bullet (x_2, y_2)$ 的公式。这一步**假设 $P_{i+1} = P_i \bullet P$ 已知**（$P$ 是基点），也就是说我们知道
$P_i - P_{i+1} = P^{-1}$ 的 $x$ 坐标 $x_P$。这就是 Montgomery 阶梯的结构：它总是同时维护 $(P^i, P^{i+1})$，两者的差恒为 $P$，于是"差分加法"总是可用。

从 (18) 出发并代入曲线方程消去 $y_1^2, y_2^2$（化简细节见论文）：

$$x_{2i+1} = \left(\frac{y_2 - y_1}{x_2 - x_1}\right)^2 - A - x_1 - x_2
= \frac{(x_1 + x_2)(1 + x_1x_2) + 2Ax_1x_2 - 2y_1y_2}{(x_2 - x_1)^2}
\tag{26}$$

分子里还剩 $-2y_1y_2$。为了消掉它，利用 $P = P_i^{-1} \bullet P_{i+1}$（把 $P_i$
的 $y$ 取反再与 $P_{i+1}$ 相加）：

$$x_P = \frac{(x_1 + x_2)(1 + x_1x_2) + 2Ax_1x_2 + 2y_1y_2}{(x_2 - x_1)^2}$$

把 (26) 与上式**相乘**，$(2y_1y_2)^2$ 项相消（再用曲线方程消去 $y_1^2 y_2^2$）：

$$x_P \cdot x_{2i+1} = \frac{(x_1x_2 - 1)^2}{(x_2 - x_1)^2}$$

整理并代入 $x = X/Z$（$Z_P = 1$，因为基点以仿射坐标给出）：

$$x_{2i+1} = \frac{Z_P (X_iX_{i+1} - Z_iZ_{i+1})^2}{X_P (X_iZ_{i+1} - X_{i+1}Z_i)^2}
= \frac{(X_iX_{i+1} - Z_iZ_{i+1})^2}{x_P (X_iZ_{i+1} - X_{i+1}Z_i)^2} \tag{27}$$

## 11.6 汇总：只用 $x$ 坐标的公式 (28)

把 (25) 和 (27) 并排写在一起：

$$X_{2i} = (X_i^2 - Z_i^2)^2, \qquad X_{2i+1} = (X_iX_{i+1} - Z_iZ_{i+1})^2 \tag{28a}$$

$$Z_{2i} = 4X_iZ_i(X_i^2 + AX_iZ_i + Z_i^2), \qquad
Z_{2i+1} = x_P\,(X_iZ_{i+1} - X_{i+1}Z_i)^2 \tag{28b}$$

它们的输入是：标量的一个比特、上一轮的 $(X_i, Z_i, X_{i+1}, Z_{i+1})$、基点 $x$
坐标 $x_P$。输出 $(X_{2i}, Z_{2i}, X_{2i+1}, Z_{2i+1})$（当前比特为 0）或$(X_{2i+1}, Z_{2i+1}, X_{2i+2}, Z_{2i+2})$（当前比特为 1，此时 $X_{2i+2}, Z_{2i+2}$
是对 $(X_{i+1}, Z_{i+1})$ 应用倍增公式得到的）。

**这些公式从不用 $y$ 坐标**——这就是 X25519 公钥只有 32 字节 $x$ 坐标的数学根源。同时，无论输入坐标和比特如何，每步执行的算术运算完全相同，这为常数时间打下了基础（第 12 章兑现）。

## 11.7 过渡实现（概念版）

直接按公式 (28) 实现（每步 14 次乘法，见第 12 章对比），可作为理解用代码：

```c
/* 概念实现：按公式 (28) 计算一步阶梯（含多余的临时变量） */
static void ladder_step_naive(field_elem X2, field_elem Z2,
                              field_elem X3, field_elem Z3,
                              const field_elem X1, const field_elem Z1,
                              const field_elem X4, const field_elem Z4,
                              const field_elem xP, const field_elem A)
{
    field_elem t1, t2, t3, t4;
    /* 倍增：X2 = (X1^2 - Z1^2)^2, Z2 = 4 X1 Z1 (X1^2 + A X1 Z1 + Z1^2) */
    fmul(t1, X1, X1);                    /* t1 = X1^2 */
    fmul(t2, Z1, Z1);                    /* t2 = Z1^2 */
    fsub(t3, t1, t2);                    /* t3 = X1^2 - Z1^2 */
    fmul(X2, t3, t3);                    /* X2 = (X1^2 - Z1^2)^2 */
    fadd(t4, t1, t2);                    /* t4 = X1^2 + Z1^2 */
    fmul(t3, X1, Z1);                    /* t3 = X1 Z1 */
    fmul(t1, t3, A);                     /* t1 = A X1 Z1 */
    fadd(t4, t4, t1);                    /* t4 = X1^2 + A X1 Z1 + Z1^2 */
    fmul(t1, t3, t4);                    /* t1 = X1 Z1 (X1^2 + A X1 Z1 + Z1^2) */
    fadd(t1, t1, t1);
    fadd(t1, t1, t1);                    /* t1 = 4 X1 Z1 (X1^2 + A X1 Z1 + Z1^2) */
    for (int i = 0; i < 16; ++i) Z2[i] = t1[i];

    /* 差分加法：X3 = (X1 X4 - Z1 Z4)^2, Z3 = xP (X1 Z4 - X4 Z1)^2 */
    fmul(t1, X1, X4);
    fmul(t2, Z1, Z4);
    fsub(t3, t1, t2);
    fmul(X3, t3, t3);                    /* X3 = (X1 X4 - Z1 Z4)^2 */
    fmul(t1, X1, Z4);
    fmul(t2, X4, Z1);
    fsub(t3, t1, t2);
    fmul(t4, t3, t3);
    fmul(Z3, xP, t4);                    /* Z3 = xP (X1 Z4 - X4 Z1)^2 */
}
```

这个版本正确但笨拙（乘法次数多、还有 `fadd` 实现 ×4）。第 12 章会把它优化到每步
10 次乘法，并重排变量以复用临时数组——那才是 `x25519.c` 里的真实代码。

## 11.8 练习

1. 展开并验证 11.4 节的恒等式：$(3x^2 + 2Ax + 1)^2 - 4(x^3 + Ax^2 + x)(2x + A)
   = (x^2 - 1)^2$。（这是最重要的代数练习，建议用纸笔或 SageMath 完成。）
2. 验证 (26)：从 $\lambda = (y_2-y_1)/(x_2-x_1)$ 出发，代入 $y_1^2 = x_1^3 + Ax_1^2 +
   x_1$、$y_2^2 = x_2^3 + Ax_2^2 + x_2$，化简得到分子 $(x_1+x_2)(1+x_1x_2) +
   2Ax_1x_2 - 2y_1y_2$。
3. 说明为什么公式 (28) 中 $X_{2i+1}$、$Z_{2i+1}$ 的推导必须假设"知道 $x_P$"。如果没有这个假设，公式会缺什么信息？
4. 解释射影坐标如何把"255 次除法"变成"1 次除法"。
5. 对比 11.7 的朴素实现与第 7 章 `fmul` 的接口，指出为什么临时变量 $t_1..t_5$
   必须用 `field_elem` 而不能用 `i64`。

## 11.9 小结

- 射影坐标 $x = X/Z$ 把除法推迟到最后，255 轮迭代只做 1 次除法。
- 点倍增公式 (25) 和差分加法公式 (27) 都**不使用 $y$ 坐标**。
- 差分加法需要已知 $P_i - P_{i+1} = P$ 的 $x$ 坐标——Montgomery 阶梯的结构恰好总是提供它。
