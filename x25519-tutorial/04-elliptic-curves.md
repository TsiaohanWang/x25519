# 第4章：椭圆曲线简介

## 4.1 什么是椭圆曲线

椭圆曲线不是椭圆，而是由魏尔斯特拉斯方程定义的代数曲线。

### 一般形式

在域 $F$ 上，椭圆曲线的一般形式为：

$$y^2 = x^3 + ax + b$$

其中 $a, b \in F$，且判别式 $\Delta = -16(4a^3 + 27b^2) \neq 0$（确保曲线非奇异）。

### Montgomery 曲线形式

Curve25519 使用的是 Montgomery 曲线形式：

$$y^2 = x^3 + Ax^2 + x$$

其中 $A = 486662$。

### 为什么选择 Montgomery 曲线

1. **高效的标量乘法**：Montgomery 阶梯算法
2. **不需要 y 坐标**：节省带宽和计算
3. **良好的安全性质**：抵抗某些侧信道攻击

## 4.2 曲线上的点

### 定义

椭圆曲线上的点是满足曲线方程的坐标对 $(x, y)$，加上一个特殊的无穷远点 $\infty$。

### 示例

对于曲线 $y^2 = x^3 + x$ 在 $\mathbb{Z}_5$ 上：

```
x = 0: y^2 = 0 → y = 0
x = 1: y^2 = 2 → 无解（2 不是模 5 的二次剩余）
x = 2: y^2 = 10 ≡ 0 → y = 0
x = 3: y^2 = 30 ≡ 0 → y = 0
x = 4: y^2 = 68 ≡ 3 → 无解
```

曲线上的点：$(0, 0), (2, 0), (3, 0)$，加上无穷远点 $\infty$。

## 4.3 椭圆曲线群

### 群运算定义

椭圆曲线上的点构成一个阿贝尔群，群运算定义如下：

1. **无穷远点**：$\infty$ 是单位元
2. **逆元**：点 $P = (x, y)$ 的逆元是 $P^{-1} = (x, -y)$
3. **点加法**：通过几何方法定义（弦切法）

### 几何解释

给定曲线上的两个点 $P$ 和 $Q$：

1. 画一条通过 $P$ 和 $Q$ 的直线
2. 该直线与曲线相交于第三点 $R$
3. $P + Q$ 是 $R$ 关于 x 轴的对称点

如果 $P = Q$，则使用切线。

### 代数公式

对于 Montgomery 曲线 $y^2 = x^3 + Ax^2 + x$：

**点加法**（$P \neq Q$）：
$$x_3 = \lambda^2 - A - x_1 - x_2$$
$$y_3 = \lambda(x_1 - x_3) - y_1$$
其中 $\lambda = \frac{y_2 - y_1}{x_2 - x_1}$

**点倍增**（$P = Q$）：
$$x_3 = \lambda^2 - A - 2x_1$$
$$y_3 = \lambda(x_1 - x_3) - y_1$$
其中 $\lambda = \frac{3x_1^2 + 2Ax_1 + 1}{2y_1}$

## 4.4 Curve25519 参数

### 曲线方程

$$y^2 = x^3 + 486662x^2 + x$$

### 域参数

- 模数：$p = 2^{255} - 19$
- 曲线阶：$8q$，其中 $q = 2^{252} + 27742317777372353535851937790883648493$
- 余因子：$h = 8$
- 基点：$g = (9, y_g)$

### 为什么选择这些参数

1. **安全性**：$q$ 是大素数，确保离散对数问题困难
2. **效率**：$p$ 接近 2 的幂，便于高效实现
3. **标准化**：经过广泛审查和标准化

## 4.6 群的阶和余因子

### 群的阶

Curve25519 椭圆曲线群的阶为 $8q$，其中：
- $q = 2^{252} + 27742317777372353535851937790883648493$ 是素数
- $8$ 是余因子

### 余因子的意义

余因子 $h = 8$ 意味着群不是素数阶的，这带来一些安全考虑：

1. **小子群攻击**：攻击者可能发送阶为 2、4 或 8 的点
2. **对策**：X25519 通过钳位处理确保私钥是 8 的倍数

## 4.7 安全性质

### 离散对数问题

给定点 $P$ 和 $Q = kP$，计算 $k$ 是困难的。这是椭圆曲线密码学安全性的基础。

### CDH 假设

给定 $P, aP, bP$，计算 $abP$ 是困难的。

### DDH 假设

给定 $P, aP, bP$，区分 $abP$ 和随机点是困难的。

## 4.9 小结

椭圆曲线提供了构建密码学群的另一种方式。与传统的基于整数的群相比，椭圆曲线群可以在更短的密钥长度下提供相同的安全性。
