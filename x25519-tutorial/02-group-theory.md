# 第 2 章：群与 Diffie-Hellman 密钥交换

> 对应论文：§2.2 群、§2.3 Diffie-Hellman 密钥交换、§2.4 群的安全性质

## 2.1 本章要回答的问题

第 4 章我们会发现，椭圆曲线上的点可以定义一种“加法”，并且这些点构成一个**群**。在走到那一步之前，本章先把“群”这个抽象概念讲清楚，并回答三个问题：

1. 群到底是什么？为什么密码学那么依赖它？
2. Diffie-Hellman 密钥交换协议是怎样工作的？它依赖群的什么性质？
3. 什么样的群才安全？为什么椭圆曲线群比“模 $p$ 整数乘法群”更好？

## 2.2 群公理

一个**阿贝尔群**是一个集合 $G$ 配上一个二元运算 $\bullet$（读作“群运算”），对 $G$ 中任意两个元素 $a, b$，$a \bullet b$ 仍是 $G$ 的元素，并且满足：

1. **封闭性**：对所有 $a, b \in G$，$a \bullet b \in G$。
2. **结合律**：对所有 $a, b, c \in G$，$(a \bullet b) \bullet c = a \bullet (b \bullet c)$。
3. **单位元**：存在 $e \in G$，使对所有 $a \in G$ 有 $e \bullet a = a \bullet e = a$。
4. **逆元**：对每个 $a \in G$，存在 $b \in G$ 使 $a \bullet b = b \bullet a = e$，记 $b = a^{-1}$。
5. **交换律**（阿贝尔群特有）：对所有 $a, b \in G$，$a \bullet b = b \bullet a$。

$G$ 中元素的个数叫**群的阶**，记作 $|G|$。如果 $|G|$ 是素数，称为**素数阶群**，它有特别好的性质（2.5 节）。

**例子 1：整数加法群 $(\mathbb{Z}, +)$**。集合是所有整数，运算是加法，单位元 0，
$a$ 的逆元是 $-a$。这是一个无限群。

**例子 2：模 $n$ 整数加法群 $(\mathbb{Z}_n, +)$**。集合 $\{0, 1, \ldots, n-1\}$，运算是“加法后模 $n$ 归约”，单位元 0，$a$ 的逆元是 $(-a) \bmod n$（$a = 0$ 时为 0）。阶为 $n$。这是有限群。

**例子 3：模 $p$ 整数乘法群 $(\mathbb{Z}_p^*, \cdot)$。** $p$ 是素数，集合$\{1, 2, \ldots, p-1\}$，运算是“乘法后模 $p$ 归约”，单位元 1。**并非显然**每个元素都有乘法逆元，但 $p$ 为素数时这是对的（可由 Bézout 恒等式证明，也可由费马小定理得出，见第 3 章）。群的阶为 $p - 1$。

这三个例子看似不同，但**数学结构相同**——它们都是群。抽象的力量在于：任何关于群的定理，对三者都成立；任何在群上工作的协议（如 Diffie-Hellman），都**不关心群具体是怎么实现的**。这一点在密码学中至关重要：协议设计者说“取一个素数阶群”，实现者可以用整数、椭圆曲线或任何其他方式去实现它，只要满足公理。

（“数学结构相同”的严格表述是**同构**：存在一个保持运算的双射 $\phi : G_1 \to G_2$，即 $\phi(a \bullet b) = \phi(a) \bullet' \phi(b)$。同构的群在密码学上完全等价——协议只依赖群公理。此段可暂时跳过，不影响后续阅读。）

## 2.3 群元素的幂与循环群

对群元素 $g$ 和非负整数 $k$，定义 $g$ 的 $k$ 次幂为把 $g$ 与自身运算 $k$ 次：

$$g^k = \underbrace{g \bullet g \bullet \cdots \bullet g}_{k \text{ 次}}, \qquad
g^0 = e, \qquad g^k = g \bullet g^{k-1} \ (k > 0)$$

注意这里 $g^k$ 只是“群运算的重复”的记号——在加法群 $(\mathbb{Z}_n, +)$ 中它就是$k \cdot g$（$g$ 加 $k$ 次）。

**幂的法则**（由结合律直接推出）：对非负整数 $a, b$，

$$g^{a+b} = g^a \bullet g^b, \qquad (g^a)^b = g^{ab}, \qquad g^{-a} = (g^a)^{-1}$$

第一条说“同底幂相乘”，第二条说“幂的幂”。Diffie-Hellman 的正确性（2.4 节）完全依赖这两条——请确认它们来自**结合律**，而不是任何其他假设：$(g^a)^b$ 就是把 $g$ 自乘 $a$ 次、再把结果自乘 $b$ 次，结合律保证两种括号方式得到同一个元素。

**子群**：如果 $H \subseteq G$ 且 $H$ 在同样的运算 $\bullet$ 下本身构成群（五条公理都满足），称 $H$ 是 $G$ 的**子群**。由 $g$ 生成的**子群** $\langle g \rangle = \{g^0, g^1, g^2, \ldots\}$：由封闭性它是 $G$ 的子集；它确实构成群，因为 $g^a \bullet g^b = g^{a+b} \in \langle g \rangle$（封闭）、$g^0 = e$（单位元）、$(g^a)^{-1} = g^{-a}$（逆元）、结合律继承自 $G$。注意 $\langle g \rangle$ 的定义不需要预先知道群是否有限。

**元素的阶**：使 $g^k = e$ 的最小正整数 $k$ 称为元素 $g$ 的**阶**，记 $\text{ord}(g)$。它恰好等于 $\langle g \rangle$ 的元素个数：$\langle g \rangle = \{g^0, g^1, \ldots, g^{\text{ord}(g)-1}\}$，且这些元素两两不同（若 $g^i = g^j$、$i < j$，则 $g^{j-i} = e$，与 $k$ 的最小性矛盾）。由**拉格朗日定理**（下一小节给出证明）：子群的阶整除群的阶，因此 $\text{ord}(g) \mid |G|$，进而 $g^{|G|} = e$。

**循环群**：如果存在 $g \in G$ 使 $\{g^0, g^1, \ldots, g^{|G|-1}\} = G$，则 $G$ 是循环群，$g$ 是**生成元**。循环群最重要的性质是：

> 如果 $G$ 是阶为 $q$ 的循环群，生成元为 $g$，那么从 $[0, q-1]$ 均匀随机选取 $k$
> 并计算 $g^k$，得到的群元素在 $G$ 中**均匀分布**。

这给了密码学一个“均匀采样群元素”的机制，后面 Diffie-Hellman 会反复用到。

**为什么素数阶群好**：可以证明素数阶群必为循环群，且除单位元外每个元素的阶都等于$|G|$。也就是说，素数阶群里没有“小圈子”——这直接关系到第 4 章要讲的**小子群攻击**。

**陪集与拉格朗日定理（证明）**。设 $H$ 是 $G$ 的子群。对任意 $a \in G$，集合

$$aH = \{a \bullet h \mid h \in H\}$$

称为 $H$ 的一个**左陪集**。两个关键事实：

1. **陪集要么相同、要么不相交**：若 $aH \cap bH \neq \varnothing$，设公共元素是 $a h_1 = b h_2$。则对任意 $h \in H$，
   $$a h = b (h_2 h_1^{-1} h)$$
   而 $h_2 h_1^{-1} h \in H$（封闭性），所以 $aH \subseteq bH$；对称地 $bH \subseteq aH$，故 $aH = bH$。
2. **所有陪集大小相同**：映射 $h \mapsto a \bullet h$ 是双射（逆映射为 $h \mapsto a^{-1} \bullet h$），所以 $|aH| = |H|$。

于是 $G$ 被划分成若干互不相交、大小都为 $|H|$ 的陪集，故 $|H|$ 整除 $|G|$。这就是**拉格朗日定理**。推论：$\langle g \rangle$ 是子群，故 $\text{ord}(g) = |\langle g \rangle|$ 整除 $|G|$。**注意整个证明只用到了群公理**——这就是“抽象的力量”：同一个证明对整数加法群、$\mathbb{Z}_p^*$、椭圆曲线群全部成立，无需逐个验证。

**循环群有多少个生成元**？设 $G$ 是 $q$ 阶循环群，$g$ 是生成元。$g^k$ 仍是生成元当且仅当 $\gcd(k, q) = 1$：若 $d = \gcd(k, q) > 1$，则 $(g^k)^{q/d} = (g^q)^{k/d} = e$，故 $g^k$ 的阶至多 $q/d < q$，不能生成整个群；反之若 $\gcd(k, q) = 1$，由 Bézout 恒等式存在整数 $u, v$ 使 $uk + vq = 1$，于是 $(g^k)^u = g^{1 - vq} = g$，即 $g$ 可以由 $g^k$ 的幂得到，$g^k$ 生成整个群。所以生成元的个数等于欧拉函数 $\varphi(q)$。例如 $\mathbb{Z}_7^*$（阶 6）：与 6 互素的 $k$ 是 1 和 5，生成元恰好 2 个——2.7 节的代码会输出它们（3 和 5）。

## 2.4 Diffie-Hellman 密钥交换

假设 Alice 和 Bob 要通过不安全的信道（攻击者只能窃听、不能篡改）协商一个共享秘密，用来加密之后的通信。Diffie-Hellman（DH）协议如下：

1. 公开参数：一个素数阶群 $G$ 及其生成元 $g$（公开，谁都知道）。
2. Alice 选随机整数 $a$ 作私钥，计算 $A = g^a$ 作公钥并公开。
3. Bob 选随机整数 $b$ 作私钥，计算 $B = g^b$ 作公钥并公开。
4. Alice 用 Bob 的公钥计算 $(g^b)^a$；Bob 用 Alice 的公钥计算 $(g^a)^b$。

由结合律，$(g^b)^a = g^{ba} = g^{ab} = (g^a)^b$，两人得到**同一个**群元素
$g^{ab}$——这就是共享秘密。而窃听者只知道 $g$、$g^a$、$g^b$（全是公开的）。

**安全性的关键问题**：窃听者能否从 $g, g^a, g^b$ 算出 $g^{ab}$？如果群选得不好，可以；如果选得好，这被认为是计算上不可行的。这就是下一节的内容。

## 2.5 群的安全性质：DLP、CDH、DDH

设 $g$ 是素数阶 $q$ 的群的生成元，$a, b, k$ 从 $[0, q-1]$ 均匀随机选取。三个层层递进的假设：

（这里“困难”的精确含义是：任何高效（多项式时间、随机化）算法成功解决相应问题的概率，至多比随机猜测多一个可忽略的量。严格定义属于计算复杂性理论，见 Katz–Lindell《Introduction to Modern Cryptography》第 8 章；本教程只需直观理解。）

- **离散对数问题（DLP）**：给定 $g$ 和 $g^k$，求 $k$ 是困难的。
- **计算性 Diffie-Hellman（CDH）**：给定 $g, g^a, g^b$，求 $g^{ab}$ 是困难的。
- **判定性 Diffie-Hellman（DDH）**：给定 $g, g^a, g^b$ 以及一个元素 $h$，判断
  $h$ 是 $g^{ab}$ 还是一个随机群元素，是困难的（即攻击者无法显著优于随机猜测）。

容易看出 DLP 困难 ⇒ CDH 困难 ⇒ DDH 困难（反过来不一定）。

**不同群的安全性质天差地别**：

- $(\mathbb{Z}_n, +)$：DLP 极易——解 $g \cdot k = x$ 就是普通除法，不安全。
- $(\mathbb{Z}_p^*, \cdot)$：DLP 被认为困难，但 **DDH 不成立**。展开论证如下。$p$ 为奇素数时，$\mathbb{Z}_p^*$ 中恰好一半元素是**二次剩余**（即某个元素的平方 $x^2$），而且平方数构成一个阶为 $(p-1)/2$ 的子群（$(xy)^2 = x^2 y^2$，封闭性成立）。**Euler 判别准则**说：$a^{(p-1)/2} \equiv \pm 1 \pmod{p}$，且 $a$ 是二次剩余当且仅当 $a^{(p-1)/2} \equiv 1$。于是攻击者**无需解离散对数**，只要做一次模幂就能判断任意元素是否平方。选定一个生成元 $g$（原根——它必为非二次剩余，因为 $g^{(p-1)/2} = -1 \neq 1$），则 $g^k$ 是平方当且仅当 $k$ 是偶数——$g^k$ 的平方性直接泄露 $k$ 的奇偶性。同理，$g^{ab}$ 的平方性由 $a, b$ 的奇偶性决定。给定 $(g, g^a, g^b)$ 和候选 $h$，攻击者检查“$h$ 的平方性是否与 $a, b$ 的奇偶性相容”，就能以严格高于 $\frac{1}{2}$ 的概率判断 $h$ 是否为 $g^{ab}$，DDH 因此不成立（论文 §2.4 的论证与此一致）。

  补救办法是取 $\mathbb{Z}_p^*$ 的**素数阶子群**（DSA 就是这么做的）：子群阶为素数 $q$ 时没有非平凡子群可供泄露信息，DDH 在其中被认为是成立的。代价是 $p$ 必须非常大：达到 128 位安全级别需要 $p$ 超过 3000 比特，密钥和消息都很大。（$\mathbb{Z}_p^*$ 本身是循环群——存在生成整个群的**原根**——这是数论中“原根存在定理”的结论，证明超出本教程范围，我们直接使用；参见 Katz–Lindell 第 8 章或任意数论教材。）
- **椭圆曲线群**（第 4 章构造）：DDH 被广泛认为成立，且相同安全级别下只需 256 位。

> **这就是椭圆曲线密码学的根本动机**：在同样的 128 位安全级别下，椭圆曲线群的元素只需 32 字节，而 $\mathbb{Z}_p^*$ 需要几百字节；网络传输更省、计算更快。

## 2.6 记号约定（重要）

群运算的记号在不同文献中不同，本教程必须统一，否则容易混淆：

- 椭圆曲线文献传统上把群运算写作**加法** `+`，$P$ 的逆元写作 $-P$，$P$ 与自身相加写作 $2P$（点倍增）。
- 密码学协议文献传统上写作**乘法** `·`，逆元写作 $P^{-1}$，$P$ 与自身相乘写作 $P^2$。

本教程沿用论文的约定：椭圆曲线群元素之间的运算用 **$\bullet$**，以区别于单个域元素（模 $p$ 的整数）之间的 $+$、$\cdot$。这样“点加法 $P \bullet Q$”和“域元素加法$a + b$”不会混淆。不过，说到 X25519 协议本身时（第 13、14 章），我们仍会说“私钥
$a$ 乘基点得到公钥 $aP$”这类惯用语，请留意上下文。

## 2.7 C 代码：验证 $\mathbb{Z}_7^*$ 是循环群

```c
#include <stdio.h>

/* 计算 a 在模 n 乘法群中的阶：最小的 k>0 使 a^k ≡ 1 (mod n) */
int element_order(int a, int n) {
    int power = 1, order = 0;
    do {
        power = (power * a) % n;   /* 依次计算 a, a^2, a^3, ... */
        order++;
    } while (power != 1);
    return order;
}

int main(void) {
    int n = 7;
    printf("Z_%d* 中各元素的阶（群的阶为 6）：\n", n);
    for (int a = 1; a < n; a++)
        printf("  元素 %d 的阶：%d\n", a, element_order(a, n));
    /* 输出：1 的阶 1；2、4 的阶 3；3、5 的阶 6；6 的阶 2。
       阶为 6（等于群阶）的元素 3 和 5 就是生成元。 */
    return 0;
}
```

## 2.9 小结

- 群是一个抽象的代数结构；素数阶群必为循环群，元素在群中均匀分布。
- DH 协议依赖“从 $g^a, g^b$ 无法算出 $g^{ab}$”。
- DLP/CDH/DDH 三个假设刻画了群的安全性；椭圆曲线群用 256 位达到 $\mathbb{Z}_p^*$
  用 3000 多位才达到的安全级别。

下一章我们把“模 $p$ 的整数”升级成**有限域**——一个同时有加法、减法、乘法和除法的结构，这是椭圆曲线方程里所有坐标运算的舞台。
