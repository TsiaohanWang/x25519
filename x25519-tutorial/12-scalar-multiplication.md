# 第 12 章：标量乘法与 Montgomery 阶梯

> 对应论文：§4.4 Montgomery 阶梯、§4.5 处理无穷远点、§4.6 优化阶梯步骤、§4.8 完成标量乘法

## 12.1 本章要回答的问题

标量乘法（计算 $P^k$，即 $k$ 次群运算）是 X25519 的核心。本章回答：

1. 朴素重复加法为什么不可行？Montgomery 阶梯怎么做到 $O(\log k)$ 且常数时间？
2. 论文把公式 (28) 优化到每步 **10 次乘法**，是怎么一步步做到的？
3. 为什么无穷远点不需要任何特殊处理？
4. `x25519.c` 中 `montgomery_ladder` 的代码与这些公式如何一一对应？

## 12.2 标量乘法与朴素算法

对群元素 $P$ 和非负整数 $k$，定义

$$P^k = \underbrace{P \bullet P \bullet \cdots \bullet P}_{k \text{ 次}}$$

朴素实现就是重复加法，复杂度 $O(k)$。$k$ 是 255 位整数时 $k \approx 2^{254}$，完全不可行。我们需要 $O(\log k)$ 的算法。

**简单的平方-乘法（double-and-add）**：按 $k$ 的二进制位从高到低，每步平方当前点，位为 1 时再乘一个 $P$。但它的运算序列依赖 $k$ 的比特（位为 0 和 1 时操作不同），是**非常数时间**的，会泄露私钥。Montgomery 阶梯解决了这个问题：无论比特是什么，每步都执行完全相同的操作。

## 12.3 Montgomery 阶梯

定义函数 $L(P, i)$，返回一对群元素 $(P^i, P^{i+1})$：

$$L(P, 0) = (\infty, P) \tag{23}$$

$$L(P, 2i) = (P_i \bullet P_i, \ P_i \bullet P_{i+1}) \quad \text{其中 } L(P, i) = (P_i, P_{i+1})$$

$$L(P, 2i+1) = (P_i \bullet P_{i+1}, \ P_{i+1} \bullet P_{i+1}) \quad \text{其中 } L(P, i) = (P_i, P_{i+1})$$

直观理解：$L(P, i)$ 的第二参数每递归一层就右移一位（$i \mapsto \lfloor i/2 \rfloor$），所以递归深度是 $\lfloor \log_2 i \rfloor$。用循环实现：从 $k$ 的最高位扫到最低位，每一轮做**一次加法 + 一次倍增**：

- 当前位为 0（$2i$ 情形）：计算 $P^{2i} = P_i \bullet P_i$ 和$P^{2i+1} = P_i \bullet P_{i+1}$，输出 $(P^{2i}, P^{2i+1})$；
- 当前位为 1（$2i+1$ 情形）：计算 $P^{2i+1} = P_i \bullet P_{i+1}$ 和$P^{2i+2} = P_{i+1} \bullet P_{i+1}$，输出 $(P^{2i+1}, P^{2i+2})$。

两种情形做的操作**完全相同**（一次差分加法 + 一次点倍增），只是把哪个结果放到哪个位置不同。利用第 11 章的“交换-计算-交换回”技巧（或第 12.6 节的惰性交换），连这个“位置差异”都可以用常数时间条件交换消除——这就是阶梯常数时间的来源。

> 为什么返回两个点而不是一个？因为差分加法需要知道 $P_i \bullet P_{i+1}$ 的输入差 $P_i^{-1} \bullet P_{i+1}$，而 $P_{i+1} = P_i \bullet P$，所以
> $P_i^{-1} \bullet P_{i+1} = P$——**差恒等于基点**，其 $x$ 坐标 $x_P$ 已知！这是整个优化的关键：维护一对相邻幂，让差分加法始终可用。

## 12.4 公式 (28) 的乘法计数

把公式 (28) 逐项分解（每项一次乘法），共用子表达式，最直接的做法需要 14 次乘法。论文的分解把**乘以常数**也算作乘法（我们的实现在所有情况下使用同一个 `fmul`），即 $v_4 = 4v_3$ 与 $v_5 = Av_3$ 各计一次：

$$v_1 = X_i^2, \quad v_2 = Z_i^2, \quad v_3 = X_iZ_i, \quad v_4 = 4v_3,
\quad v_5 = Av_3 \quad \text{（倍增，5 次乘法）}$$

$$X_{2i} = (v_1 - v_2)^2, \qquad Z_{2i} = v_4(v_1 + v_5 + v_2)$$

$$v_6 = X_iX_{i+1}, \quad v_7 = Z_iZ_{i+1}, \quad v_8 = X_iZ_{i+1}, \quad
v_9 = X_{i+1}Z_i \quad \text{（加法，4 次乘法）}$$

$$X_{2i+1} = (v_6 - v_7)^2, \qquad Z_{2i+1} = x_P(v_8 - v_9)^2
\quad \text{（加法结果，3 次乘法：} X_{2i+1} \text{ 1 次，} Z_{2i+1} \text{ 2 次）}$$

加上 $X_{2i}$、$Z_{2i}$ 各自的组合乘法，总计 14 次乘法（若把乘常数视为免费则是
12 次）。论文 §4.6 的优化把这个数字压到 10 次——见下一节。

论文 §4.6 展示了如何把公共子表达式重新组织，降到 **10 次乘法**（外加 8 次加减）。下面推导这个优化——它是 `x25519.c` 中阶梯代码的直接来源。

## 12.5 10 次乘法的优化分解

设迭代开始时 $a = X_i$，$b = X_{i+1}$，$c = Z_i$，$d = Z_{i+1}$，基点 $x = x_P$。逐步执行（每行对应一次 `fadd`/`fsub`/`fmul`，注意变量重用）：

$$
\begin{array}{lll}
\text{指令} & \text{数学含义} & \text{说明} \\
\texttt{fadd(e, a, c)} & v_1 = a + c & \\
\texttt{fsub(a, a, c)} & v_2 = a - c & \\
\texttt{fadd(c, b, d)} & v_3 = b + d & \\
\texttt{fsub(b, b, d)} & v_4 = b - d & \\
\texttt{fmul(d, e, e)} & v_5 = v_1^2 = (a+c)^2 & \\
\texttt{fmul(f, a, a)} & v_6 = v_2^2 = (a-c)^2 & \\
\texttt{fmul(a, c, a)} & v_7 = v_3 \cdot v_2 = (b+d)(a-c) & \\
\texttt{fmul(c, b, e)} & v_8 = v_4 \cdot v_1 = (b-d)(a+c) & \\
\texttt{fadd(e, a, c)} & v_9 = v_7 + v_8 = 2(ab - cd) & \text{差分加法分子} \\
\texttt{fsub(a, a, c)} & v_{10} = v_7 - v_8 = 2(ad - bc) & \text{差分加法分母} \\
\texttt{fmul(b, a, a)} & v_{11} = v_{10}^2 = 4(ad-bc)^2 & \\
\texttt{fsub(c, d, f)} & v_{12} = v_5 - v_6 = 4ac & \\
\texttt{fmul(a, c, \_121665)} & v_{13} = 121665 \cdot v_{12} = (A-2)ac & \\
\texttt{fadd(a, a, d)} & v_{14} = v_{13} + v_5 = a^2 + Aac + c^2 & \\
\texttt{fmul(c, c, a)} & v_{15} = v_{12} \cdot v_{14} = 4ac(a^2 + Aac + c^2) & = Z_{2i} \\
\texttt{fmul(a, d, f)} & v_{16} = v_5 \cdot v_6 = (a^2 - c^2)^2 & = X_{2i} \\
\texttt{fmul(d, b, x)} & v_{17} = v_{11} \cdot x = 4x(ad-bc)^2 & = 4Z_{2i+1} \\
\texttt{fmul(b, e, e)} & v_{18} = v_9^2 = 4(ab-cd)^2 & = 4X_{2i+1}
\end{array}
$$

关键观察：

- $v_{15} = 4ac(a^2 + Aac + c^2) = Z_{2i}$、$v_{16} = (a^2-c^2)^2 = X_{2i}$：倍增结果（对照公式 (25)）。✓
- $v_{17} = 4x(ad-bc)^2 = 4Z_{2i+1}$、$v_{18} = 4(ab-cd)^2 = 4X_{2i+1}$：差分加法结果（对照公式 (27)）。✓
- **因子 4 的奥秘**：$X_{2i+1}$ 和 $Z_{2i+1}$ 都带上了因子 4，而射影坐标只关心比值 $x_{2i+1} = X_{2i+1}/Z_{2i+1}$，两个 4 **相互抵消**，不影响任何后续计算。这是“多做一点、但更快”的典型例子：省掉两次乘法，代价是表示多一个无害的因子。

于是每步的输出是 $(X_{2i}, 4X_{2i+1}, Z_{2i}, 4Z_{2i+1})$，分别写入变量$(a, b, c, d)$。**为什么能只算一次 $v_{13}$ 而不分别算 $Av_3$**？因为$121665 = (A-2)/4$，于是 $121665 \cdot 4ac = (A-2)ac$，配合 $v_5 = (a+c)^2$ 得到$a^2 + Aac + c^2$。**而 `x25519.c` 用的是另一个等价组合**，见下一节。

## 12.6 x25519.c 中的阶梯代码

仓库里的 `montgomery_ladder` 采用**等价的另一种常数组合**：用
$a24 = 121666 = (A+2)/4$ 搭配 $(a-c)^2$：

$$\frac{A+2}{4} \cdot 4ac + (a-c)^2 = (A+2)ac + a^2 - 2ac + c^2 = a^2 + Aac + c^2$$

与论文的 $\frac{A-2}{4} \cdot 4ac + (a+c)^2 = a^2 + Aac + c^2$ **结果完全相同**。（这正是 RFC 7748 §5 用 $121665$、TweetNaCl 用 $121666$ 的原因——两种写法都对，只是配对的项不同。第 10 章练习 1 让你记住这两个常数，现在派上用场。）

```c
/* (A+2)/4 = (486662+2)/4 = 121666 */
a24_fe[0] = 121666;
for (i = 1; i < 16; i++) a24_fe[i] = 0;

/* 初始化：R0 = O（射影表示为 (1:0)），R1 = P = (x_in : z_in) */
x0[0] = 1; z0[0] = 0;
for (i = 1; i < 16; i++) { x0[i] = 0; z0[i] = 0; }
for (i = 0; i < 16; i++) { x1[i] = x_in[i]; z1[i] = z_in[i]; }

for (i = 254; i >= 0; --i) {
    int bit = (k[i / 8] >> (i % 8)) & 1;   /* 小端字节数组的第 i 位 */

    /* 根据 bit 常数时间地交换 (x0,z0) 与 (x1,z1) */
    swap25519(x0, x1, bit);
    swap25519(z0, z1, bit);

    /* ---- 差分加法：x1/z1 = X_{2i+1}/Z_{2i+1}（含因子 4） ---- */
    fadd(t1, x0, z0);   /* t1 = x0 + z0        (v1) */
    fsub(t2, x0, z0);   /* t2 = x0 - z0        (v2) */
    fadd(t3, x1, z1);   /* t3 = x1 + z1        (v3) */
    fsub(t4, x1, z1);   /* t4 = x1 - z1        (v4) */
    fmul(t5, t1, t4);   /* t5 = (x0+z0)(x1-z1) (v8) */
    fmul(t6, t2, t3);   /* t6 = (x0-z0)(x1+z1) (v7) */
    fadd(t7, t5, t6);   /* t7 = v8+v7 = 2(x0x1-z0z1)  (v9) */
    fsub(t8, t5, t6);   /* t8 = v8-v7 = -2(x0z1-x1z0) */
    fmul(x1, t7, t7);   /* x1 = t7^2 = 4X_{2i+1}       (v18) */
    fmul(t8, t8, t8);   /* t8 = t8^2 = 4(x0z1-x1z0)^2  (v11) */
    fmul(z1, x_in, t8); /* z1 = x_in * t8 = 4Z_{2i+1}  (v17) */

    /* ---- 倍增：x0/z0 = X_{2i}/Z_{2i} ---- */
    fadd(t1, x0, z0);
    fmul(t1, t1, t1);   /* t1 = (x0+z0)^2              (v5) */
    fsub(t2, x0, z0);
    fmul(t2, t2, t2);   /* t2 = (x0-z0)^2              (v6) */
    fmul(x0, t1, t2);   /* x0 = (x0^2-z0^2)^2 = X_{2i} (v16) */
    fsub(t3, t1, t2);   /* t3 = t1-t2 = 4x0z0          (v12) */
    fmul(t4, a24_fe, t3);   /* t4 = 121666*4x0z0 = (A+2)x0z0 */
    fadd(t5, t2, t4);   /* t5 = (x0-z0)^2 + (A+2)x0z0 = x0^2+Ax0z0+z0^2 */
    fmul(z0, t3, t5);   /* z0 = 4x0z0(...) = Z_{2i}    (v15) */

    /* 交换回来，恢复 (x0,z0)=(低幂), (x1,z1)=(高幂) 的顺序 */
    swap25519(x0, x1, bit);
    swap25519(z0, z1, bit);
}
```

对照第 12.5 节：`t8 = v8 - v7 = -v10`，符号差在平方后消失，所以
`x1 = t7² = v18`、`z1 = x·t8² = v17` 与论文一致。倍增部分用 $121666$ 配$(x0-z0)^2$，数学上等价（见上）。每步 10 次 `fmul`（差分加法 6 次 + 倍增 4 次）
+ 8 次 `fadd/fsub`。

**位提取 `(k[i/8] >> (i%8)) & 1`**：`k` 是 32 字节小端数组，第 $i$ 位在字节
`k[i/8]` 的第 `(i%8)` 位。循环从 254 到 0（最高位 bit 254 起），共 255 次迭代。（旧版教程误写为 `i/64`、`i%64`，那是对 64 位数组的写法，这里必须用 `i/8`。）

## 12.7 初始化与收尾：scalarmult 的完整结构

```c
/* 初始化（论文 §4.8）：L(P,0) = (∞, P) = ((1:0), (x:1)) */
a = 1, c = 0;      /* 低幂点 = ∞ */
b = x_in, d = 1;   /* 高幂点 = P */

/* 255 轮阶梯后：a/c = 结果点的 x 坐标（射影形式） */

finverse(c, c);    /* c := c^{-1} —— 整个标量乘法唯一一次除法 */
fmul(a, a, c);     /* a := a * c^{-1} = 仿射 x 坐标 */
pack25519(out, a); /* 打包成 32 字节 */
```

对照 `x25519.c` 的 `x25519()`：`montgomery_ladder` 输出 `(x_out, z_out)`，然后 `finverse(inv_z, z_out)`、`fmul(result, x_out, inv_z)`、`pack25519(out, result)`。

**为什么只需一次逆元**？因为 255 轮迭代都在射影坐标里进行（无除法），结束时才把分子分母合并成仿射坐标。这就是第 11 章“把除法推迟到最后”的兑现。

## 12.8 无穷远点：无需任何特殊处理

初看 $\infty$ 是个麻烦（仿射坐标无法表示），但射影坐标 $Z = 0$ 恰好表示它，且**公式 (28) 自动正确处理 $\infty$**。论文 §4.5 的证明思路（假设 $x_P \ne 0$，这对基点 $x=9$ 成立）：

- 输入 $(X, Z) \ne (0, 0)$ 时，输出也 $\ne (0, 0)$（逐个情形检查，唯一的反例需要 $A = \pm 2$，被 $A^2 \ne 4$ 排除）；
- $Z_i = 0$（$P_i = \infty$）时，$X_{2i} = X_i^4 \ne 0$、$Z_{2i} = 0$，输出仍是 $\infty$，符合 $\infty \bullet \infty = \infty$；
- $P_i^{-1} = P_{i+1}$ 时，$Z_{2i+1} = 0$，输出 $\infty$，符合$P_i \bullet P_{i+1} = \infty$。

结论：**阶梯不需要检查任何边界情况**——这不仅简化代码，更让每一步都执行相同指令，是常数时间的重要前提。注意这里有个微妙点：如果**基点** $P$ 的阶为 2
（即 $x_P$ 对应的点满足 $2P = \infty$），某些中间情形需要 $x_P \ne 0$ 的假设；
X25519 的基点阶为 $q$（第 10 章），没有问题。攻击者若提供小阶点，结果会是 0，
RFC 7748 建议接收方检查全零输出（第 14 章）。

## 12.9 练习

1. 用 $k = 5$（二进制 101）手工追踪阶梯：列出每轮 $L(P, i)$ 的值，验证最终 $a/c$ 是 $P^5$ 的 $x$ 坐标。
2. 验证 12.6 节两个常数组合的等价性：$121665 \cdot 4ac + (a+c)^2 = 121666 \cdot 4ac + (a-c)^2 = a^2 + Aac + c^2$。
3. 数一遍 `montgomery_ladder` 每次迭代的 `fmul` 调用次数，确认是 10 次。
4. 解释因子 4 为什么无害（提示：射影坐标只关心 $X/Z$ 的比值）。
5. 为什么阶梯从 bit 254 开始而不是 bit 255？提示：标量 $k$ 是标量乘法的**输入**，与 u 坐标无关；钳位保证 $k < 2^{255}$（bit 255 恒为 0）且 bit 254 恒为 1
   （第 13 章），所以有效比特只有 bit 254..0 共 255 位。
6. 阅读论文 §4.5 的证明，说明为什么“输入 $(X,Z) \ne (0,0)$ 则输出也$\ne (0,0)$”对常数时间性很重要。

## 12.10 小结

- Montgomery 阶梯维护 $(P^i, P^{i+1})$，每轮一次差分加法 + 一次倍增，操作序列与比特无关 → 常数时间。
- 差分加法需要 $P_i^{-1} \bullet P_{i+1} = P$ 的 $x$ 坐标——阶梯结构天然提供。
- 公式 (28) 优化为每步 10 次乘法；`x25519.c` 用 $121666$ 配 $(x-z)^2$，与论文的 $121665$ 配 $(x+z)^2$ 等价。
- 无穷远点被自动处理，无需分支；整个标量乘法只在结尾做一次除法。

至此，曲线算术完成。下一部分把标量乘法组装成真正的 X25519：密钥生成与密钥交换。
