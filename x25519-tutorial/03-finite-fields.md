# 第 3 章：有限域与乘法逆元

> 对应论文：§2.5 有限域、§2.6 循环群与乘法逆元

## 3.1 本章要回答的问题

第 4 章要定义的椭圆曲线方程 $y^2 = x^3 + Ax^2 + x$ 中，$x, y$ 是"数"。这些数从哪里来？答案：从**有限域**来。本章回答：

1. 域和群有什么区别？为什么椭圆曲线的坐标必须生活在域里？
2. 什么是"除法"？为什么 $\frac{b}{a}$ 其实是"$b$ 乘以 $a$ 的逆元"？
3. 乘法逆元怎么算？为什么密码学用费马小定理 $a^{p-2}$ 而不是扩展欧几里得算法？

## 3.2 域公理

一个**域**是一个集合 $F$ 配上两个运算 $+$ 和 $\cdot$，满足：

1. $(F, +)$ 是阿贝尔群，单位元记 0；$a$ 的加法逆元记 $-a$。减法 $a - b$ 是 $a + (-b)$ 的简写。
2. $(F \setminus \{0\}, \cdot)$ 是阿贝尔群，单位元记 1；$a$ 的乘法逆元记 $a^{-1}$。（0 被排除，因为它没有乘法逆元。）除法 $\frac{a}{b}$ 是 $a \cdot b^{-1}$ 的简写。
3. 分配律：$a \cdot (b + c) = a \cdot b + a \cdot c$。

熟悉的例子：有理数 $\mathbb{Q}$、实数 $\mathbb{R}$、复数 $\mathbb{C}$ 都是域。关键是：**域里有四种运算**——加、减、乘、除——都按我们熟悉的代数规则工作，包括"解方程"：$ax + b = c$ 可以解出 $x = (c - b) \cdot a^{-1}$。这一点对第 4 章推导椭圆曲线群律至关重要（那里要解直线与曲线的交点方程）。

## 3.3 素数域 $\mathbb{Z}_p$

当 $F$ 的元素个数有限时，称为**有限域**（Galois 域）。最简单的有限域是**素数域**：$p$ 为素数时，

$$\mathbb{Z}_p = \{0, 1, \ldots, p-1\}$$

配上"模 $p$ 加法"和"模 $p$ 乘法"构成一个域。逐条验证：

- $(\mathbb{Z}_p, +)$ 是阿贝尔群：封闭性、结合律显然；单位元 0；$a$ 的加法逆元是$p - a$。
- $(\mathbb{Z}_p \setminus \{0\}, \cdot)$ 是阿贝尔群：封闭性、结合律显然；单位元 1。**唯一不显然的是每个非零元素都有乘法逆元**——这由下面的费马小定理保证。
- 分配律：模运算下显然。

> 如果 $p$ 不是素数，$\mathbb{Z}_p$ 就不是域：例如 $\mathbb{Z}_6$ 中 $2 \cdot 3 = 0$，非零元素相乘得到 0（这样的元素叫零因子），$2$ 没有乘法逆元。所以素数性质是"域"的命门，也是 Curve25519 选素数的原因。

**Curve25519 的域**：$\mathbb{Z}_p$，其中 $p = 2^{255} - 19$。此后教程中"域元素"一律指模 $p$ 的整数；"域乘法"指模 $p$ 乘法；"域除法 $\frac{b}{a}$"指$b \cdot a^{-1} \bmod p$，结果仍是 $[0, p-1]$ 的整数，**不是分数**。

## 3.4 乘法逆元与费马小定理

**费马小定理**：若 $p$ 是素数且 $a \not\equiv 0 \pmod{p}$，则

$$a^{p-1} \equiv 1 \pmod{p}$$

（直觉：$\mathbb{Z}_p^*$ 的阶是 $p-1$，由拉格朗日定理，任何元素的阶整除 $p-1$，故 $a^{p-1} = e = 1$。）由此立刻得到

$$a \cdot a^{p-2} \equiv a^{p-1} \equiv 1 \pmod{p}$$

所以 **$a$ 的乘法逆元是 $a^{p-2} \bmod p$**。这是一个干净、统一的公式：求逆元变成一次模幂运算。对 Curve25519，$p - 2 = 2^{255} - 21$，是一个 255 位整数；用平方-乘法（第 1 章的 `mod_pow` 思路）只需约 255 次平方和约 253 次乘法，可行。

**为什么不用扩展欧几里得算法？**扩展欧几里得算法也能求逆元，而且理论上更快。但它的执行时间取决于输入的具体值（辗转相除的步数随输入变化），**不是常数时间**。密码学中，如果运算时间泄露了关于秘密的信息，攻击者可以用时序分析（第 6 章）恢复秘密。费马小定理方法用**固定的**平方-乘法序列，天然容易实现为常数时间。论文明确指出了这一点。第 8 章我们会看到 `finverse` 正是利用 $p - 2$ 的二进制结构硬编码了这个固定序列。

## 3.5 C 代码

下面的代码用平方-乘法实现费马小定理求逆元。注意：为了讲清思路，这里用 `long long`
并假设所有值都小于模数；Curve25519 的 $p$ 是 255 位，无法放进 `long long`，第 5 章起我们才处理真正的 255 位算术。

```c
#include <stdio.h>

/* 平方-乘法：计算 base^exp mod mod */
long long mod_pow(long long base, long long exp, long long mod) {
    long long result = 1;
    base %= mod;
    while (exp > 0) {
        if (exp & 1)
            result = (result * base) % mod;
        exp >>= 1;
        base = (base * base) % mod;
    }
    return result;
}

/* 费马小定理：a 的乘法逆元 = a^(p-2) mod p（p 为素数） */
long long mod_inverse(long long a, long long p) {
    return mod_pow(a, p - 2, p);
}

int main(void) {
    long long p = 7;
    printf("Z_%lld 中非零元素的乘法逆元：\n", p);
    for (long long a = 1; a < p; a++) {
        long long inv = mod_inverse(a, p);
        printf("  %lld^{-1} = %lld （验证 %lld * %lld mod %lld = %lld）\n",
               a, inv, a, inv, p, (a * inv) % p);
    }
    return 0;
}
```

## 3.7 小结

- 域 = 两种群结构 + 分配律；$\mathbb{Z}_p$（$p$ 素数）是最简单的有限域。
- 域除法是乘以逆元；逆元可由费马小定理 $a^{-1} \equiv a^{p-2} \pmod{p}$ 计算。
- 常数时间要求排除了扩展欧几里得算法，确定了 $a^{p-2}$ 路线。
